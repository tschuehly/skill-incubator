Search index migration
FlowStepsRisks

Data flow

Writes go to both indexes for two weeks. Reads switch only after the shadow comparison stays under 0.5% mismatch for seven days.

Rollout steps

1 · Dual write

Every write lands in both indexes. Cost: about 18% more write latency at p95.

2 · Shadow read

1% of reads also query the new index; the comparer logs every differing result.

3 · Cutover

Reads switch region by region. Rollback is a flag flip while dual write is still on.

Risks

  • Ranking changes are visible to customers even when every document matches.
  • Dual write doubles indexing cost for two weeks.
  • The comparer samples only 1% of reads, so rare queries may never be compared.
