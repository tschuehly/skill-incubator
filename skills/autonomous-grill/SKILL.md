# Autonomous Grill

Compose `/agent-orchestration` with either the active runtime's model-orchestration capability or a composing skill's validated fixed binding contract; apply `/domain-modeling` only to accepted outcomes. Verify both model families resolve; report a blocker if neither routing source is available. Pi Workbench owns the supported dynamic model-orchestration skill.

Distill the target, facts, constraints, and unresolved decisions. One lead synthesizes while one persistent opposite-family deliberation advisor challenges the opening decision tree.

Grill autonomously, one consequential decision at a time. Resolve discoverable facts from code and supplied documents. The lead recommends; the advisor challenges assumptions, alternatives, evidence, contradictions, and dependencies; the lead revises or records dissent. Exchange compact deltas for up to three rounds, extending only when new evidence changes a proposal.

Give the same advisor the settled proposals for a closing completeness audit. Send every material gap back through the grill.

Report numbered proposals with the decision, rationale, strongest alternative, evidence, risk, and dependencies. List unresolved dissent.

Keep every proposal pending. Ask the human to `accept D…`, `reject D…: reason`, or `revise D…: constraint`. Ratify accepted IDs; reopen rejected or revised IDs and their dependents. Implementation requires a separate request.

Finish when the closing audit finds no material gap and every consequential branch is a supported proposal or unresolved dissent.
