# quality-loop: guardrails are scripts, orchestration is a skill

The quality-loop skill is a re-entrant prose driver. Mechanical gates—RED/GREEN validity,
baseline comparison, session scope, Chapter state transitions, delivery preflight, and any
explicitly configured numeric change-size limit—are shell scripts whose output the agent quotes.
Gate attempts retain immutable logs and manifests in the file-backed Run Record. Exclusive
workspace leases serialize commands that mutate shared build outputs. Review-board fan-out may use
isolated worktrees while the Ledger remains the durable authority across session boundaries.
